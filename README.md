# Oasis: All Platform Gaming Social Hub 🎮

Oasis is a specialized desktop application designed to bridge the gap between social communication platforms and game library management systems. By integrating **Discord-style** real-time interaction with **Steam-style** game tracking, Oasis provides a singular, lightweight environment for gamers to manage their digital assets and social circles.

### 🌐 Powered by Peer-to-Peer Technology

<div style="text-align:center;">
  <img src="https://peerjs.com/img/logo.png" alt="PeerJS Logo" width="250"/>
</div>
Oasis offers low-latency communication and presence synchronization using <b>PeerJS</b>. This ensures real-time interaction, direct peer connectivity, and a robust infrastructure for social gaming without the need for heavy centralized servers.

---

## 📌 Overview

- _Name_: Oasis
- _Type_: Unified Social Gaming Platform
- _Track_: Desktop Application (Electron + React)
- _Built For_: Software Engineering Project (AOL)
- _Focus_: Real-time communication, game library management, and performance optimization
- _Source of Income (Simulated)_:
  - Game transactions and subscription-based premium social features
- _Modules_:
  - **Social Layer**: Real-time chat, voice, and video calls via PeerJS
  - **Gaming Layer**: Game library management with RAWG API integration
  - **Presence System**: Globally synchronized user states and activity
  - **Persistence**: Localized JSON storage via LocalStorage

---

## 🔥 Features

- 🎭 **Real-time Social Interaction**:
  - **Peer-to-Peer Chat**: Send and receive messages instantly via PeerJS.
  - **Voice & Video Calls**: High-quality communication directly between users.
  - **Presence Sync**: See what your friends are playing in real-time.

- 🎟 **Game Library Management**:
  - **Discover**: Browse trending games and deals powered by RAWG API.
  - **Library**: Track owned games, installation states, and playtime.
  - **Game Detail**: Rich metadata, screenshots, and custom backgrounds for every title.

- ✅ **Presence Management**: Synchronized user states (Online, Idle, DND, In-Game).

- 🛡 **Secure Authentication**: Local registration and login with encrypted password handling and session management.

- 🔄 **Localized Persistence**: All data is stored locally using optimized JSON structures in LocalStorage for instant access.

- 💰 **Economic Simulation**: Simulated purchase flow and library expansion.

- 📅 **Event Scheduling (Future Update)**: Community gatherings and gaming session planning.

---

## 🎯 Problem Solved

Modern gamers are forced to manage multiple heavy applications (Launchers, Chat apps) that consume significant system resources. Oasis addresses these challenges by providing:

- **Resource Efficiency**: Targeted idle RAM usage of < 500MB, suitable for 8GB RAM systems.
- **Unified Experience**: Combines social features and game management in one "tactical" aesthetic interface.
- **Zero Server Lag**: Uses PeerJS for direct communication, reducing reliance on centralized server latency.
- **Privacy & Speed**: Localized data persistence ensures your library data loads instantly without waiting for cloud sync.

- _CSS (Modular)_ — Custom Nebula Design System
- _LocalStorage_ — JSON-based persistence

```bash

```

```bash
npm start
```
